# CertSnatcher — estensione Firefox

Per provarla, caricala come componente aggiuntivo temporaneo:

1. Apri `about:debugging#/setup` in Firefox e vai su **Questo Firefox**.
2. Clicca **Carica componente aggiuntivo temporaneo** e scegli `src/manifest.json`.

L'estensione ha bisogno del backend avviato su `http://localhost:8080/certsnatcher-ms`.
Istruzioni complete nel [README principale](../../../README.md).
